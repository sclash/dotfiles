# Network-Center

- ***Command: *** `SUPER + w`

It should pop up window structured as such:

- What network the machine is currently connected to showing:
    - Network Name
    - Signal intensity
    - Ipv4 address
    - Wich, if any VPN we're connected to.
    - I should be able to diconnect from the current network.

- I should see the following options:
    - Known networks
    - Scan Networks
    - VPN

- ***Known Networks: *** 
    - All know networks
    - Wether or not are available
    - Forget network
    - Every new wifi connection should be automatically added to the list of known
    networks

- ***Scan Networks: *** 
    - All Networks available, with intensity signal
    - Connect to a network being automatically prompted to enter a password

- ***VPN: *** 
    - All VPN currently set up.
    - Connect to a VPN.
    - Delete a VPN connection
    - Add a new VPN connection.
