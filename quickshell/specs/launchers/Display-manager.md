# Display-Manager

- ***Command: *** `SUPER + d`

It should pop up window structured as such:

- What monitor the machine is currently connected to showing:
    - Device Name

- Availble monitors to connect to:
    - Connect to a monitor:
        - Extend
        - Duplicate
        - Only on that monitor

- If connected to more than one monitor:
    - disconnect from a given monitor.
    - if in `extend` mode I should be able to show the orientation 'left' 'right' 'top' 'bottom'.
